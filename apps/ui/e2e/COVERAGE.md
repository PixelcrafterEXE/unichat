# What the e2e suite covers (mock UI, headless Chromium)

## Covered
- **messages.ts**: attach popup open/outside-click; reaction chip tooltip + who-reacted modal; reply-quote jump/highlight; react from context menu; edit (+ "(edited)"); delete placeholder; load earlier; in-chat search jump beyond loaded window; global search; message grouping; send + status ticks; attachments / location / contact card render; voice message player (play, speed); no Send via/badges in plain chats.
- **voice.ts**: recording with a fake microphone (timer, 1 s gate, send, discard), duration/waveform helpers.
- **folders.ts**: rail seed rules (collapsed single-chat communities, folders, provider dots), mixed-network folder, move via menu/modal + reset, new folder (colour/icon), edit/delete folder, reorder (menu + drag), drag chat to rail, unread badge follows moves, mute community, dynamic single-chat collapse + community info, collapse setting, emptied community vanishes, provider bubble, moved chats' avatar vs `#`, custom folder icon upload.
- **merge.ts**: merge from menu/info panel, unified timeline ordering/badges, Send via (default, capability-adaptive composer, badges, schedule, no reload, round trip), per-message actions (react/reply/edit/delete/forward/quote jump), merged search, live events, unread/preview/notifications/rename, pin/mute/archive, contact panel (networks, make primary, merge more), signed-out member + account removal, unmerge, narrow viewport.
- **discord.ts**: categories (headings, collapse, persistence), cards, counts, polls, bot-vs-user capabilities incl. live change, mentions (autocomplete, filter, keys, structured send, no autocomplete in DMs / unsupported providers).
- **requests.ts**: approximate unread dot, message requests (accept/decline/reply), provisional chat resolution, login warning + required checkbox, warning severities, login form select + expandable help, add-account provider list/icons.
- **activity.ts**: archive lowers Home badge, notification + unread count + clear, mute silences notifications.
- **groups.ts**: group picture upload/remove, member avatars, description editor (edit/save/cancel/clear, capability off, DM), "your own name" form.
- **settings.ts**: backup export (passphrase rules, warning, progress, result), import (errors, inspect, result, moved accounts), single-chat export. **backup.ts** (other agent): desktop dialogs + move-login wizard.
- **railgroups.ts**: drop an icon on the middle of another = new rail group (members, badge sum, muted rule, expand/collapse, mini-icon tile), join via header/member drop, edge drops reorder / take a member out, whole-group drag, rename/colour, Remove from group, Ungroup, keyboard `Add to group…` and Move up/down, chats dropped on a group choose a member, vanished members are dropped.
- **categories.ts**: user categories (seed Hiking Club: user Planning + empty Gear ideas + provider Official): order user-before-provider, counts / unread totals, create (header, space menu, duplicate refused, colour), collapse remembered across reload, rename / colour / move up-down / delete with fallback, Move to category… (single, No category, Provider category reset, New category from the dialog), bulk (bar + menu), drag chat to heading / row, drag heading reorder, move to another place clears the category, deleted folder takes its categories, Personal view + Mark category as read, keyboard (Enter/Space/menu key).
- **select.ts**: shift+click range / ctrl+click toggle / plain click / Escape, selection bar (Move, Archive, Mute, Mark as read, Clear), bulk context menu, drag of a selected row moves all, failure summary keeps failed chats selected, merged rows, highlight screenshot.
- **video.ts**: square 300/148 tiles, no browser controls, first-frame + duration badge, click/Space/Enter play/pause, one video at a time, progress/mute/expand controls, lightbox player, 'Cannot play here' + Download (QuickTime), GIF unchanged, auto-download off.
- **discord.ts** (also): grouped follow-ups line up with the first message in flat/bubbles x normal/compact for Discord channels and WhatsApp groups.
- **app.ts**: error boundary absent on normal screens, boundary shown on a render crash, no uncaught exceptions.

## Not covered
- Real providers, the Hub/server, Electron/desktop shell (only a faked `window.unimsg` in backup.ts).
- Visual correctness: screenshots are not diffed (`--update-shots` only writes them); themes/message styles/responsive layout are hardly asserted.
- Real audio playback output, real media recording quality; Ogg conversion is only exercised through the fake mic.
- Drag and drop is synthetic DragEvents, not OS drag; real keyboard shortcuts (Ctrl+K quick switcher, Ctrl+Shift+F) not tested.
- Lightbox/image viewer (the video lightbox is covered), location/event/poll creation modals, contact sharing, forward of attachments, profile/privacy modals, join/leave community, add/remove members, block, QR login flow and relink, message-request edge cases beyond the above, Mesh groups, mark-all-read, typing indicator timing, accessibility.
- No test of the in-app notifications permission prompt.
- **search.ts**: global search query language (prefix, phrase, diacritics), operators from:/in:/has:/after:/before:/-exclude and their error messages, filter chips edit the query, keyboard navigation + open at the highlighted message, chat/contact name hits, "in this chat" scope chip and the chat-header search with operators.
- **fetchhistory.ts**: "Fetch chat history" only for messengers with `fetchHistory`, progress / finish summary, cancel, chat selection, failure counts per reason.
- **pickers.ts**: the shared emoji picker (all emojis, search, categories + sticky header, skin tone setting, recent / frequently used, keyboard, phone bottom sheet; composer, reaction "+" and chip, folder icon), the shared-media gallery (compact sidebar grid + "Show all (N)", tabs, paging, lazy thumbnails, viewer, Show in chat, older backend fallback, phone full screen) and the account status ring row (colours, tooltip, click opens the account card, 44px on a phone).
